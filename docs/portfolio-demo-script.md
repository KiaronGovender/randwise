# RandWise Portfolio Demo Script

## 45-second LinkedIn video flow

1. Open the dashboard and show the ZAR money health score.
2. Click Upload CSV and import `sample-data/capitec-demo-statement.csv`.
3. Show the dashboard refreshing with income, spending, cash flow, and savings rate.
4. Highlight the spending map with South African categories like prepaid electricity, airtime, groceries, and fuel.
5. Scroll to Debit Order Detective and show yearly recurring costs.
6. Show the AI coach section with practical next-month actions.
7. Open Goals and show the emergency fund recommendation.

## Post caption

I built RandWise, a personal finance coach for South Africans.

It imports bank statements, categorises spending, detects recurring debit orders, and turns transaction history into practical savings recommendations.

Stack: Svelte, TypeScript, Laravel, PHP, CSV parsing, API tests.

What I wanted to show: product thinking, local context, clean dashboards, backend data processing, and a real workflow beyond CRUD.
